📚 Library Management System

A simple, menu-driven Library Management System built using Java. This project is designed to practice core programming concepts by managing books through a command-line interface.

✨ Features

- ➕ Add new books
- 🔍 Search for books
- 📖 Issue books
- ↩️ Return books
- 📋 Display available book information
- 🚪 Exit the program

🛠️ Technologies Used

- Language: Java
- Concepts: Classes, Objects, Methods, Conditional Statements, Loops
- Interface: Console / Command Line

🚀 How to Run

1. Install Java

Install a Java Development Kit (JDK) on your computer.

2. Clone the Repository

git clone https://github.com/exeleviackerman-web/Library-Management.git

3. Open the Project Folder

cd Library-Management

4. Compile the Program

Replace "LibraryManagement.java" with your actual Java filename if necessary.

javac LibraryManagement.java

5. Run the Program

java LibraryManagement
